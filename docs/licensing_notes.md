# Licensing and Data-Use Notes

Before using a dataset or codebase:

1. Read the original license and terms.
2. Confirm whether use is restricted to research/non-commercial work.
3. Confirm whether redistribution is prohibited.
4. Cite the original paper and dataset record.
5. Do not commit patient data, restricted datasets, model weights with redistribution restrictions, or credentials to GitHub.
6. Keep a `DATA_LICENSES.md` file in downstream projects documenting the exact version/source of every dataset.

## Important

The dataset catalog in this repository is informational. A link here does not imply that the data are unrestricted or suitable for commercial use.
